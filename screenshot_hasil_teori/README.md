# Screenshot Hasil Teori

Folder terpisah berisi screenshot output saat contoh kode teori dijalankan
(`python teori/teori_N_*.py`), satu screenshot per soal teori:

1. `screenshot_teori_1_parameter_vs_argumen` — parameter vs argumen
2. `screenshot_teori_2_legb_scope` — aturan LEGB
3. `screenshot_teori_3_mutable_default_pitfall` — pitfall mutable default
4. `screenshot_teori_4_module_vs_package` — module vs package
5. `screenshot_teori_5_lambda_vs_def` — lambda vs def

Setiap screenshot tersedia sebagai `.png` (dan versi `.svg` dengan isi yang sama).
